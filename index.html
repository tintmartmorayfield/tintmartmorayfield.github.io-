Tint Mart Morayfield — Calendar Sync Tool
Last updated: September 2026

This is an internal tool used solely by Tint Mart Morayfield to automate transferring booking details from our Google Calendar into our internal admin booking system.

What it accesses: This tool connects to a single Google Calendar account (belonging to Tint Mart Morayfield) using the Google Calendar API, with permission to read calendar events and edit event descriptions on that same account.

How the data is used: Calendar event details (customer name, phone number, vehicle information, and job notes contained in event titles/descriptions) are read and used only to automatically create matching bookings in our own internal admin system. After a booking is synced, this tool appends a short status note back into the original calendar event's description.

Who can access this data: This tool is for internal use only, by Tint Mart Morayfield staff, on our own Google account. It is not distributed to, or used by, any other person, business, or organization.

Data sharing: No calendar data is shared with, sold to, or transmitted to any third party. Data flows only between our own Google Calendar and our own internal booking system.

Data retention: A local record of already-synced event IDs is kept to avoid duplicate bookings. No calendar data is stored anywhere outside our own systems.
